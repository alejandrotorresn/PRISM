# Logs Layout

The logs tree is organized by workflow so the root directory remains readable.

- `experiments/` contains logs generated by `scripts/run_experiments.sh`.
- `thesis_mode/` contains logs generated by `scripts/run_thesis_mode.sh`.
- `thesis_smoke_workflow/` contains logs generated by `scripts/run_thesis_smoke_workflow.sh`.
- `grid5k/` contains launcher-side logs generated by `scripts/launch_grid5k.sh`.
- `archive/` stores older traces that are no longer part of the active working set.

The shell scripts accept `LOG_DIR=...` if a host needs a different destination.
